# Архитектура

## Части

1. `index.html` + `src/style.css` — интерфейс: меню, экраны настройки, HUD игры, панель просмотра.
2. `src/flag.js` — `function FlagArt(){...}`: флаги (узоры, эмблемы, случайный флаг). Самодостаточна, уходит в workers.
3. `src/gen.js` — `function WorldGen(SEED,OPT){...}`: детерминированный генератор мира и рендер тайлов. Выполняется и в main thread, и в каждом Web Worker.
4. `src/main.js` — `function startWorld(cfg)`: движок (камера, ввод, кеш тайлов, анимация, свет, погода, облака, панель просмотра). Режимы `view` / `bg` / `game`, хуки игры, `destroy()`.
5. `src/game.js` — `Game`: государства, основание столиц, территория, экономика, боты, месторождения, туман, сохранения, HUD.
6. `src/ui.js` — меню, настройка новой игры, настройки, пауза, иконки, запуск (адрес с `#seed` → просмотр, иначе меню).

## Поток игры

меню (`startWorld` в режиме `bg`) → «Создать мир» → `Game.newGame`: мир без столиц (`mode:'game'`), фаза `found` → клик и «Да» → `Game.found`: боты выбирают места, мир пересобирается с `opt.caps`, фаза `play` → тик `sim(0.1 с)` из хука `frame` с учётом скорости. Сохранение — `Game.save` (конфиг с `caps` + состояние), загрузка — тот же путь с готовыми столицами.

## Детерминизм

Весь мир выводится из SEED через хеши (`mix32`, `hh`, `rng`) и шум Перлина. Каждый worker сам вызывает `WorldGen(seed)` (≈450–620 мс) и получает тот же мир, поэтому данные между потоками не передаются. Worker создаётся из Blob: `WorldGen.toString()` + обработчик сообщений.

## Тайловая пирамида

- Тайл 256×256, уровни z = 0…12, `mpp = 512 / 2^z` (z0 — весь мир, z12 — 0,125 м/px).
- Уровень: `z = ceil(log2(WORLD/(256*mppDev)) - 0.25)`, DPR тайлов ограничен 1,5.
- Пока тайл не готов, рисуется растянутый кусок ближайшего готового предка. Всегда запрашиваются z0 и уровень z-3.
- Кеш LRU на ImageBitmap; z ≤ 3 не вытесняются. Отдельные кеши: `cache` (день), `stale` (старый сезон, служит подложкой при смене сезона), `LCS[1..3]` (огни: резкие, bloom×4 на z-1, bloom×8 на z-3).
- Workers: `hardwareConcurrency-2` (от 2 до 5), очередь по расстоянию до центра экрана, тайл возвращается через `OffscreenCanvas.transferToImageBitmap`.
- Fallback: без workers или OffscreenCanvas тайлы рендерятся в main thread с бюджетом на кадр (принудительно — `#<seed>cpu`, например `#1337cpu`).

## Рендер тайла `renderTile(z,tx,ty)`

1. **Raster.** Тяжёлые поля (высота, реки, влажность, лес, сельхоз-маска, урбанизация) считаются на сетке 4 px и интерполируются. На пиксель приходятся только дешёвые операции: деталь, зерно, кроны Worley, смешивание биомов, hillshade. Вода полупрозрачная, под ней main thread рисует блики. Сезоны: `seasonC(c,mode)` и сезонные ветки в `raster()`.
2. **Vector** (мировые координаты через setTransform): pass 0 — подложки кварталов и зон → дороги (`drawRoads`, `ORDER=[5,4,3,6,2,7,1,0]`) → путепроводы → pass 1 — тени (по кварталам) → pass 2 — крыши, псевдо-3D фасады (`LEAN`), объекты, деревья-спрайты.
3. **Grain.** Мировой шум и хеш-зерно поверх векторов.

Тайл огней — `renderLights(z,x,y,hb)`: фонари по таблице `LAMP`, окна на фасадах (`facadeLights`), объекты (`drawLightPrims`). Пустой тайл → `null`. Bloom рендерится с полями 32 px, поэтому без швов.

Пороги LOD (mpp тайла): кварталы массами при > 14; LITE при > 2,2; LITE2 при > 4,5; улицы при < 22; проспекты при < 40; машины на парковках при < 1,8; кроны леса при < 1,7. Межтайловый кеш кварталов — `BCACHE`.

## Дороги

`k`: 0 магистраль, 1 трасса, 2 проспект, 3 улица, 4 деревенская, 5 ж/д, 6 рампа, 7 бульвар, 8 ЛЭП (только `drawPower`). Линии сетки города: `lineKind(n)` (n%8 → бульвар, n%4 → проспект, иначе улица). После зон генерируются: развязки (`JUNC` → `addClover`), пересечения и путепроводы (`r.ov`), АЗС, вокзалы, ЛЭП.

## Транспорт (аналитический)

Полоса — `[offset, dir, speed, spacing]`; позиция машины k: `s = k*sp + (T*v + phase) mod L + jitter`. Считаются только машины в видимых интервалах дорог, стоимость O(видимых). Поезда, суда и самолёты — тоже функции времени. Позиции машин пишутся в `CB` (Float32Array) и переиспользуются для фар.

## Порядок кадра

вода → тайлы → тени облаков → транспорт, дым, самолёты → туман → multiply ambient → огни (тайлы, фары, поезда, суда, ветряки, факелы) → осадки → облака → дымка, молния, виньетка → подписи, выделение.

Свет: `LG = {el, amb, day, night, lights, cloud}` из времени суток `tod` и погоды `wcur` (плавно стремится к `WX[wxi]`). Адаптивное качество: средний уровень bloom отключается при FPS < 22 дольше 3 с.

## Карта кода `WorldGen`

| Функция / данные | Назначение |
| --- | --- |
| `noise`, `baseH` | Перлин; высота (warp на низких октавах, горы ridged multifractal) |
| `riverV`, `riverW`, `landE` | Реки, проверка суши |
| `cities`, `buildCity`, `pickType`, `buildVillage` | Поселения, сетка `us/vs`, кварталы (типы 1–19) |
| `mkRoad`, `connect`, `routePts`, `bridgesOf`, `posAt` | Дороги, spatial grid 1024 м |
| `placeZone`, `genZone`, `emitters` | Промзоны, НПЗ, ТЭЦ, порт, аэропорт, СЭС, АЗС, вокзалы, фермы и т.д. |
| `genBlock`, `genVillage`, `drawPrims`, `roof`, `cylDraw` | Примитивы кварталов и их отрисовка |
| `gfUnits`, `gfGround`, `gfFacade`, `gfCanopies` | Первые этажи (`p.gf`) и доки складов (`p.dk`): витрины, подъезды, лобби, навесы, фуры |
| `mapShape`, `ISL`, `SZO/SZR`, `LAKT` | Опции карты этапа 5: формы суши, размер, озёра |
| `CAPS` → `capC`, тип 21, зона `mil`, `vehSprites`/`drawVeh`, `drawFlagPole` | Столицы, правительственный квартал, военные базы, техника, флагштоки |
| `GROW`, `setGrow`, `growT`, `growRoads`, `streetIv`, `featOn` | Рост столиц |
| `raster`, `grain`, `renderTile`, `renderLights`, `drawFeat` | Генерация тайлов |
| `sprites`, `drawShip`, `drawPlane` | Спрайты |

В main: `drawTiles`, `request/dispatch/evict`, `updateCam/zoomAt/flyTo`, `drawTraffic`, `drawTrains`, `drawShips`, `drawEmitters`, `drawTurbines`, `drawFlights`, `drawClouds`, `drawLabels`, `updHUD`.
